KONTEKS PROYEK UNTUK LLM
================================================================================
Nama proyek: Jawara Obira — Website portal informasi Desa Kawasi & Soligi (Pulau Obi)
Lokasi repositori: root proyek
Tujuan file ini: memberikan konteks ringkas dan navigasi kode agar model LLM cepat memahami struktur, tech stack, alur data, dan titik-titik penting untuk pengembangan/penyesuaian.
Terakhir disinkronkan dengan kode: 2026-09-03.

1) Ringkasan singkat
- Portal web KKN UGM untuk mendokumentasikan: profil desa, berita, budaya, UMKM, TOGA (tanaman obat), fauna lokal, galeri, peta fasilitas/kadastral, dan dokumentasi KKN (tim, jurnal, proker).
- Tema visual: "Retro Heritage / Neobrutalist Archive" — kertas arsip lama, palet oseanik-tropis, hard-shadow brutalist. Sumber kebenaran design system: `CLAUDE.md`.
- Memiliki panel admin (`/admin`) untuk mengelola seluruh konten, dengan theming per-section yang mengikuti warna tile dashboard-nya (lihat §7).

2) Tech stack utama (versi aktual)
- Next.js 16.2.12 (App Router, Turbopack). CATATAN: convention `middleware.ts` sudah deprecated di Next 16, seharusnya migrasi ke `proxy.ts` (peringatan muncul tiap `next dev`, belum dikerjakan).
- React 19.2.8, TypeScript (strict mode aktif)
- Tailwind CSS v4 — CSS-first config lewat `@theme` di `app/globals.css`, TIDAK ada `tailwind.config.ts` (itu memang benar untuk v4)
- Supabase (Postgres, Auth, Storage) via `@supabase/supabase-js` ^2.106.1 & `@supabase/ssr` ^0.12.4
- Rich text editor: TipTap ^3.23.6 (`@tiptap/react` + starter-kit)
- Animasi: Framer Motion (interaksi/micro-interaction) + GSAP ^3.15.0 dengan ScrollTrigger (scroll-reveal terpusat, lihat §7)
- Cloudinary ^2.10.0 (upload gambar via `/api/cloudinary/sign`)
- Playwright ^1.62.1 tercantum di package.json TAPI BELUM di-`npm install` (folder `node_modules/@playwright` tidak ada) — belum bisa dipakai untuk automated browser testing sampai dependency-nya benar-benar terpasang.
- Utilities: slugify, lucide-react

3) Cara menjalankan (singkat)
- Instal dependencies: `npm install`
- Jalankan dev: `npm run dev` (http://localhost:3000)
- Build: `npm run build` ; Start: `npm start`
- Perlu env vars Supabase & Cloudinary di `.env.local` (contoh di README.md)
- CATATAN KEAMANAN: `.env.local` saat ini punya `NEXT_PUBLIC_SUPABASE_SERVICE_ROLE_KEY` — prefix `NEXT_PUBLIC_` di key rahasia ini keliru (secara konvensi Next.js, apapun yang berprefix itu berpotensi ter-bundle ke client). Saat ini tidak dipakai di kode manapun jadi belum benar-benar bocor, tapi sebaiknya di-rename tanpa prefix supaya tidak menjebak pemakaian di masa depan.

4) File & folder penting (entry points)
- `app/` — App Router. Pola wajib per route: `page.tsx` = Server Component async (fetch via `lib/supabase/queries.ts`), interaktivitas dipisah ke child `"use client"` `XxxClient.tsx`. Hampir semua route data sudah punya `loading.tsx`+`error.tsx` sendiri.
  - `app/(home)/page.tsx` → homepage (route group, sudah dipindah dari `app/page.tsx` lama)
  - `app/layout.tsx` → root layout (Navbar + Footer global)
  - `app/globals.css` → global styles, design tokens (`@theme`), utility hard-shadow
  - `app/admin/` → dashboard & manajemen konten, 9 domain (KKN, Berita, Budaya, UMKM, Galeri/Foto, Peta Fasilitas, Fauna, Toga, Profil Desa)
  - `app/api/` → API routes: `auth/login`, `auth/logout`, `cloudinary/sign`, `gmaps/resolve`, `toga/plants`
  - `app/auth/callback/route.ts` → OAuth callback (`exchangeCodeForSession`)
  - `middleware.ts` (root) → guard `/admin` & `/login` via `supabase.auth.getUser()`; matcher: `/admin/:path*`, `/login`, `/auth/callback`

- `components/` — UI & form components
  - `components/ui/` → primitif shadcn: `button.tsx`, `card.tsx`, `badge.tsx`, `skeleton.tsx`, `Toast.tsx`, `scroll-area.tsx`, `separator.tsx`, `MotionCard.tsx`, `FloatingCard.tsx`, `AnimatedBadge.tsx` — SUDAH diadopsi luas (CultureCard, UMKMCard, FaunaCard, TogaCard, GaleriCard, + komponen admin), bukan lagi kode mati.
  - `components/shared/` → lintas-fitur beneran: `AnimatedBackground.tsx` (konsolidasi dari 5 versi terpisah), `EntityCardShell.tsx`, `EntityEmptyState.tsx`, `EntitySearchForm.tsx`, `EntityGallerySection.tsx`, `BackgroundOrnaments.tsx`, `RotatingHiasanBackground.tsx`, `MapZoomControl.tsx`, `Reveal.tsx` (wrapper GSAP ScrollTrigger, lihat §7).
  - `components/home/*` → `HeroSection.tsx`, `StatsSection.tsx`, `PotensiBento.tsx`, `KKNSection.tsx`, `CounterNumber.tsx` (odometer angka statistik), `HomeFadeIn.tsx`
  - `components/admin/*` → form per-domain (NewsForm, CultureForm, UMKMForm, TogaPlantForm, FaunaForm, KKNJournalForm, KKNProkerForm, KKNTeamForm, PetaFacilityForm) + `SectionBanner`/`Card` per domain dengan accent warna mengikuti tile dashboard-nya (lihat §7)
  - `components/kkn/*` → `KKNJournalHero.tsx`, `KKNProkerHero.tsx`, `KKNTeamHero.tsx`, `KknPageBackground.tsx`, `kknAccent.ts`, `kknCardStyles.ts`, `detail/`
  - `components/layout/*` → `Navbar.tsx`, `Footer.tsx` — link nav sekarang dari `constants/nav.ts` (single source of truth, tidak lagi hardcode berbeda-beda)

- `lib/` — utilitas & client
  - `lib/supabase/client.ts` → browser supabase client
  - `lib/supabase/server.ts` → server supabase client (cookies/session)
  - `lib/supabase/queries.ts` → satu-satunya tempat query Server Component (~50 fungsi)
  - `lib/auth.ts` → `getAdminUser()`, satu-satunya guard admin
  - `lib/animations.ts` → Framer Motion variants bersama (fadeInUp, staggerContainer, dll)
  - `lib/scrollReveal.ts` → sistem GSAP ScrollTrigger terpusat (lihat §7)
  - `lib/utils.ts` → helper umum (termasuk `cn()`)

- `hooks/` — HANYA `useCroppedImageUpload.ts` saat ini. `useHomePageData.ts`, `useFaunaData.ts`, `useCultureData.ts` yang disebut di versi lama file ini SUDAH TIDAK ADA — homepage & halaman publik lain sekarang full server-fetch (lihat §7), bukan client-side hook lagi.

- Root config
  - `package.json`, `next.config.ts`, `tsconfig.json`, `postcss.config.mjs`, `eslint.config.mjs`
  - `.github/workflows/supabase-keepalive.yml` → cron ping ke Supabase REST 2x/minggu supaya project free-tier tidak auto-pause karena 7 hari tanpa aktivitas (COMMIT LOKAL SUDAH ADA, cek apakah sudah di-push ke origin).

7) Konvensi & titik perhatian untuk LLM (arsitektur yang sudah mapan — ikuti pola ini, jangan reimplement dari nol)
- Pola wajib per route data: Server Component `page.tsx` (fetch via `queries.ts`) + child `"use client"` `XxxClient.tsx` untuk interaktivitas. Homepage sudah migrasi ke pola ini (`app/(home)/page.tsx`, bukan hook client-side lagi).
- Scroll-reveal SATU bahasa gerak untuk seluruh situs: `<Reveal kind="rise|stagger|panel">` (`components/shared/Reveal.tsx`) yang manggil `applyReveal()` di `lib/scrollReveal.ts` — pakai `gsap.from()` supaya konten tetap terbaca kalau JS gagal/`prefers-reduced-motion` aktif. Framer Motion `lib/animations.ts` tetap dipakai untuk micro-interaction (hover/tap), bukan untuk entrance scroll.
- Card/EmptyState/SearchForm generik: `EntityCardShell`, `EntityEmptyState`, `EntitySearchForm`, `EntityGallerySection` di `components/shared/` — dipakai Budaya, UMKM, Fauna, Toga, Galeri. Kalau nambah domain listing baru, compose dari sini, jangan bikin `XxxCard.tsx` baru dari nol.
- Theming admin panel: 9 domain admin (KKN, Berita, Budaya, UMKM, Galeri/Foto, Peta Fasilitas, Fauna, Toga, Profil Desa) SENGAJA meniru warna tile dashboard-nya masing-masing (pola diagonal 3-warna: primary/tertiary/cream) — lihat comment di `components/admin/AdminOrnaments.tsx`. Ini keputusan sadar, bukan inkonsistensi.
- Nav links: satu sumber `constants/nav.ts`, dipakai `Navbar.tsx` & `Footer.tsx` — jangan hardcode array link lagi.
- Auth: `middleware.ts` + `lib/auth.ts` (`getAdminUser()`) pakai `supabase.auth.getUser()` (tervalidasi server). `Navbar.tsx` (badge admin di navbar publik) sengaja pakai `getSession()` (lokal, tanpa round-trip) karena cuma UI hint, bukan gerbang keamanan — supaya tidak ikut menyumbang beban ke Supabase Auth rate limit di setiap page view publik.
- Upload gambar: `ImageUploader.tsx`/`ExtraImageUploader.tsx` → Cloudinary via `/api/cloudinary/sign`.

11) Riwayat insiden: rate-limit Supabase Auth & "infinite reload" (2026-09-02/03)
- Kronologi: project Supabase sempat auto-pause (free tier, >7 hari tanpa
  aktivitas DB) → DNS project NXDOMAIN → setelah di-restore, muncul
  `AuthApiError: over_request_rate_limit` (429) berulang-ulang di terminal
  dev server, dan terpisah dari itu, browser sempat infinite-reload beberapa
  kali dengan penyebab BERBEDA-BEDA di tiap kejadian:
  a. Cache Turbopack (`.next/`) korup akibat build yang berulang kali
     ke-interrupt saat drama koneksi — fix: `rm -rf .next` lalu `npm run dev`
     ulang. Ini yang paling sering jadi penyebab reload-loop di sesi ini.
  b. Tab browser lama masih pegang referensi chunk hash dari proses dev
     server sebelumnya (Turbopack ganti hash tiap restart) — fix: tutup tab
     lama, buka tab/incognito baru.
  c. Dev server proses background MATI SENDIRI tanpa disadari (bukan bug
     kode) — kalau port 3000 tidak ada yang listen, sebagian browser retry
     koneksi terus-menerus dan kelihatan seperti infinite-reload. SELALU cek
     dulu apakah `next dev` benar-benar masih jalan (`lsof -iTCP -sTCP:LISTEN
     | grep 3000`) sebelum mendiagnosis lebih jauh sebagai bug frontend.
  - Root-cause beban rate-limit yang sebenarnya: `Navbar.tsx` memanggil
    `supabase.auth.getUser()` (round-trip ke server) di SETIAP halaman
    publik, ditambah `middleware.ts` yang juga `getUser()` di setiap request
    `/admin`/`/login`. Sudah di-fix: `Navbar.tsx` sekarang pakai
    `getSession()` (baca cookie lokal, tanpa network call) — lihat §7.
  - Investigasi TERBUKTI BUKAN penyebabnya: infinite-loop React akibat
    `useEffect` tanpa dependency array yang benar / `onAuthStateChange` —
    sudah diperiksa satu-satu, tidak ada pola itu di codebase (grep
    `onAuthStateChange` nol hasil, semua `useEffect` terkait auth punya `[]`).
  - Mitigasi jangka panjang: `.github/workflows/supabase-keepalive.yml` —
    ping REST ke tabel `villages` 2x/minggu supaya project tidak ke-pause
    lagi (lihat §4 & `TODO_BELUM_DIKERJAKAN.txt` #6 soal status push-nya).

12) Bypass auth /admin untuk dev lokal (SEMENTARA, per 2026-09-03)
- Supaya bisa tetap edit UI saat Supabase Auth kena rate-limit, `/admin`
  bisa diakses TANPA login lewat flag di `.env.local`:
  `DISABLE_ADMIN_AUTH=true`
- Implementasi ada di 2 tempat, keduanya di-gate ganda
  (`NODE_ENV === "development"` DAN flag di atas) supaya mustahil aktif di
  production:
  - `middleware.ts` → return early sebelum sempat panggil
    `supabase.auth.getUser()`, jadi tidak ada redirect ke `/login`.
  - `lib/auth.ts` → `getAdminUser()` return fake `User` object
    (`id: "dev-bypass"`, `email: "dev@localhost"`) tanpa sentuh Supabase.
- PENTING: `.env.local` TIDAK ikut ter-commit/ter-push (standar
  `.gitignore`). Setelah clone ulang, kalau bypass ini masih dibutuhkan,
  baris `DISABLE_ADMIN_AUTH=true` harus ditambahkan manual lagi ke
  `.env.local` yang baru — kode di `middleware.ts`/`lib/auth.ts` sudah ikut
  ter-push jadi tidak perlu ditulis ulang.
- Untuk mengembalikan ke perilaku normal (wajib login): hapus/comment baris
  `DISABLE_ADMIN_AUTH=true` dari `.env.local`, lalu restart dev server. Kode
  bypass di `middleware.ts`/`lib/auth.ts` boleh dibiarkan permanen di kode
  (aman, tidak aktif tanpa flag) atau diminta untuk di-revert kalau mau
  bersih — belum diputuskan per tanggal file ini ditulis.
