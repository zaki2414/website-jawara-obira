6. POLA CODING
================================================================================

Admin Form Pattern:
1. Route /app/admin/[section]/page.tsx
   → Menampilkan daftar menggunakan getAll*() function

2. Route /app/admin/[section]/[id]/page.tsx
   → Mengambil data dengan getBy*() function
   → Merender form component (e.g., KKNTeamForm.tsx)

3. Component /components/admin/*Form.tsx
   → Menerima data awal (dari parameter)
   → Handle create/update logic menggunakan create*/update* function
   → Handle delete menggunakan DeleteButton.tsx dengan delete* function

Public Pages Pattern:
1. Route /app/[section]/page.tsx
   → Menampilkan list menggunakan getAll*() atau search function
   → Support filter/search dengan query parameters

2. Route /app/[section]/[slug]/page.tsx
   → Mengambil detail dengan getBySlug() function
   → Menampilkan konten lengkap

3. Layout sharing:
   → Navbar dan Footer digunakan di seluruh page
   → Global styles di globals.css
